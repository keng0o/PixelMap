# レール生成まで線路トポロジーを保持する

standalone testの地上鉄道は、線路中心セルを一つの集合へ混ぜて局所的な縦横方向を推測せず、元の線路ごとに接線と距離位相を保持したまま左右レールと枕木を生成する。左右レールを個別の4連結経路とし、路盤、枕木、レールの順に合成することで、斜線路の点描化より構造線の連続性を優先する。

表示解像度内で全体が並走し両端も近い線路だけは鉄道表示代表へ間引くが、元の線路データは統合・削除しない。交差線と分岐線は残し、まずstandalone testの地上鉄道だけで検証してから本番、トンネル、索道へ範囲を広げる。
