# 周囲の空きに合わせた道幅と道端の砂利

2026-09-06 JST。依頼「道幅が均一すぎる。建物などに干渉しないように太さを変え、道の脇に砂利・影のようなものを配置」への対応。style IDは `illustrated-landscape-hand-drawn-v10`。

## 対象

**testのみ**。standaloneの明示的な `profile=illustrated-landscape&presentation=art` から開く専用ページ。本番1・2・4マップ、通常standalone、旧topdown、素材ラボ、mobileは変更しない。元の道路中心線と建物・水域の地理形状は編集しない。

## 描画

- 道の左右を別々に、world座標に固定した53単位周期の滑らかなノイズで変化させる。細かな縁の揺らぎを重ね、生活道路・小径は半幅の0.58〜1.65倍、主要道路の拡張は1.22倍までに制限する。交差点の接続部では基準幅へなじませ、曲がり角は同じ可変半径を使う面でつなぐ。
- 地表の道路は建物の実形状、水域、樹冠を保護領域として参照する。各側に向かって距離を調べ、空きのある側にだけ広げる。サンプル間・端部も最終ポリゴンの差分で保護する。樹冠は描画上の最大外形より大きい保守的な円で判定する。z13の集約された市街地の面では追加の拡張を抑え、元の道路を切り抜かない。橋・鉄道・桟橋は固定幅を維持し、橋が水面を横断する既存の扱いを保持する。
- 最終的な道端の外側に小さな角のある砂利、明るい縁、途切れる薄い土色の筆跡を配置する。world座標の5単位格子をずらし、32単位の粗いノイズで疎密と空白を作る。規則的な点列にせず、パンしても同じ場所に同じ模様が残る。
- 砂利は半径1.45、土の筆跡は半径3.7の範囲に全描画を収める。道・橋・鉄道・水域・建物・樹冠・畑との判定はこの全範囲に余白を足して行う。
- 彩色、輪郭線と影の受け面は引き続き同じ描画用道路ポリゴンを参照する。データzoomの切替方針はV9のまま。
