# 輪郭線の筆圧・太細の検証

2026-09-06 JST。ユーザーの指摘「全ての輪郭の線の太さが均一で細い。参考画像のような手書きの線にしたい」への修正。style IDは `illustrated-landscape-hand-drawn-v7`。

## 対象と変更

**testのみ**。standaloneの明示的な `profile=illustrated-landscape&presentation=art` で開く専用ページと架空の構成見本。本番1・2・4マップ、通常standalone、旧topdown、素材ラボ、mobileへの変更なし。

従来のペンは一定幅の線に小さい筆圧区間を重ねており、外周の太細が弱かった。森林では外周線の内半分がその後の塗りで隠れ、さらに細く見えていた。

- `inkStrip` は、幅が連続的に変わる線を左右の縁で囲んだ面として描く。短い太線の継ぎ目が丸い粒として重ならない。角の延長を制限し、閉じた輪郭の内側を塗りつぶさない。
- 屋根・単木は同じ地物の同じ位置に筆圧が現れるようseedと線に沿う距離を使い、既存の微小な線の揺れを残す。屋根の外周は原則1.65px、単木は1.4px、庭木は0.9pxを基準に0.5〜1.6倍の筆圧をつける。小さい屋根の線には別の上限を使う。
- 森林の外周は塗りで隠れる内半分を考慮し、2.7pxを基準とする帯を下に描く。森林内部の樹冠の短い線は弱くする。
- 道と川岸はworld座標で固定した筆圧を用い、面の結合で輪郭の開始点が変わっても同じ地理位置に太細を残す。道は0.95px、川の岸は1.3pxを基準に、薄い区間と濃い区間を滑らかにつなぐ。
- 橋は接続した橋面ごとに線幅へ上限を設け、極細の歩道橋でも明るい橋面を残す。基準幅の上限は橋面幅の20%。
- 畑・葉・屋根内部の細線、彩色、形状、道路接続、中洲、樹木配置、影の計算は維持する。

## 調整過程と検証

初回は太細を強くしすぎたため、屋根と単木の黒い膨らみ、道と川岸の紡錘形の反復、畑の数珠模様が出て独立レビューFAIL。輪郭の最大幅と変動幅を抑え、内部の細線を従来の表現へ戻した。修正版11画像はPASS。その後、影のpixel検証で極細の歩道橋の輪郭が橋面を埋める条件が見つかり、橋幅による上限を追加した。

- `node --test tests/*.test.mjs`：376件PASS。
- `node build.mjs`：82ファイル。`git diff --check` PASS。
- `scripts/check-illustrated-landscape.cjs`：fixture/city/river/greenのPC・mobile、およびcity/river/greenのDPR2、計11画像を撮影。既存8項目（樹木のパン、筆跡pixel、橋・水面・中庭、岸と中洲への塗り漏れ、位置情報成功/拒否mock、通信復帰と直前地図保持、明示入口）がPASS。pixel比較専用Canvasにreadback向け設定を明示し、同位置の再描画差は0。24pxパンでは82,368 pixel中13 pixelに最大RGB差2、平均最大RGB差0.000195があるだけで、従来の許容内。陸地・中洲25,030 pixelへの水面塗り漏れ0。
- `scripts/check-illustrated-ink.cjs`：同じ地物をV6/V7のrendererで描いた比較図と一本の線の実pixel測定。CSS px換算で最小0.814・最大2.692、約3.31倍の太細を確認。端点を除いた区間が0.7〜2.8px内で、最小が1.3px未満、最大が2px超、比率が1.8倍超であることを検証する。
- `scripts/check-illustrated-shadows.cjs`：高さによる影4項目PASS。細い橋面のRGBは239/234/210、水面の影は162/186/183、その間の明るい水面は182/204/202。橋面自身の影pixelは0で、既存の判定を変更せずに通過した。

画像と結果は `screenshots/illustrated-pressure-ink-2026-09-06/` に保存。最終版11地図＋筆圧比較＋高さ比較の13画像は独立レビューPASS。輪郭の太細と内部線の強弱、細い橋面の連続性、初回の黒面・数珠状反復の解消、mobile/DPR2での判読性を確認した。実機での検証は含まない。
