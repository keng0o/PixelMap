# 建物・植生・橋の自動陰影の検証

2026-09-05 JST。ユーザーが承認した「建物・森・単木・橋を共通光源で計算し、手描きの質感を保つ」を実装。style IDは `illustrated-landscape-hand-drawn-v5`。

## 対象

**testのみ**。`variants/map-02-refined.html?profile=illustrated-landscape&presentation=art` の専用ページと、その架空の構成見本に適用。本番1・2・4マップ、通常standalone、旧topdown、素材ラボ、mobileへの変更なし。実地理の建物外形・道路・水域・中庭、植生配置の生成規則は維持した。画面外から入る影も扱うため、地物を用意する余白は64から96 world単位へ拡張した。

## 計算と描画

- `assets/illustrated-landscape-shadows.js` に高さと投影計算を分離。共通光源は左上、仰角68度。地図を真上から描く既存Canvasを維持し、建物を押し出す変更はない。
- 建物は `render_height` / `height`、次に `building:levels` を利用。欠ける場合は屋根形式や用途から推定する。屋根は既存の切妻・寄棟・複合翼などの面に対応して、軒と棟の高さを持たせる。
- 樹木は既存の樹冠形状を使い、種類・半径・seedから高さを推定。上面と下面を持つ簡単な丸い樹冠として扱う。庭木も対象。
- 橋は `min_height` / `bridge:height` があれば利用し、なければ道路種別から3.5mまたは6mを推定。厚みのある橋桁として扱い、その下の空間を残す。`layer` や車両の通行制限高さから橋桁の高さは推測しない。トンネルは対象外。
- 実地図では各地物の緯度でメートルをMercator world単位へ換算する。画面中心の変化で高さが変わらないよう、地物自身の座標を使う。
- world座標の1単位格子に、見えている受け面の高さ・材質、遮光物の上端・下端を記録。光の進む方向に走査し、物体が占める高さの区間を伝播する。受け面の高さが区間内に入る場合だけ影を描く。橋桁のような薄い物体が格子間で消えないよう、格子が占める幅も投影区間へ含める。
- 中庭は地面として残し、壁から入る影を計算する。隣の低い屋根にも影が落ち、高い屋根は低い物体に遮られない。重なった影の透明度を加算しない。
- 地面・水面・屋根・樹冠・橋桁で影の顔料色を変え、world座標に固定した薄い色むらを加える。影の境界だけを、受け面の種類と高さを保った3×3のcoverageでなじませる。地物本体や輪郭はぼかさない。
- 既存の屋根・葉の手描き彩色を保ち、明暗方向を共通光源へ合わせる。足元の短い接地色は細く残し、高さによる投影影と分離。紙目と現在地マーカーは影の後に描く。

## 精度と範囲

日照解析ではなく彩色地図のための近似。光源と地面の高さは固定し、DEM、実際の日時、崖や堤防の標高、煙突や橋脚の個別形状は追加していない。樹冠は葉を一枚ずつ計算するモデルではない。同じ格子では最も高い物体の遮光区間を記録し、複数段の高架が重なる内部構造までは解かない。

高い建物の影が地図を覆わないよう、投影長が約72 world単位以内に収まる計算用高さへ上限を設ける。元の高さ属性は保持し、上限に達した件数も診断値へ記録する。高さ情報の有無と、実測の正確さは同義ではない。

city-mobileの計算対象581件は属性・階数由来577件、推定4件で、上限適用3件。green-mobileは644件中、属性・階数由来187件、推定457件。件数には画面外の計算余白を含む。

最新の地図11画像と `height-comparison.png` はすべて独立視覚レビューPASS。市街地の影の段差、森林の暗部、道路・中庭の視認性、低い屋根・高い屋根・橋の隙間を確認。静止画の範囲で公開を止める問題なし。実機の検証は含まない。

390×844 CSS・DPR 2のheadless Chromeで、毎回影を計算し直すCanvas paint時間の中央値はcity 131.0ms、river 69.1ms、green 172.3ms。1回のウォームアップ後4回を測定。同じsceneの再描画では計算した影をキャッシュする。既存のドラッグ中のCanvas移動を維持し、毎pointermoveで投影を計算する変更はない。V4より再描画の負荷は増えており、実機の速度保証ではない。
