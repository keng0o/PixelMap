# レール生成まで線路トポロジーを保持する

standalone testと本番1・2・4マップの地上鉄道は、線路中心セルを一つの集合へ混ぜて局所的な縦横方向を推測せず、元の線路ごとに接線と距離位相を保持したまま左右レールを生成する。左右レールを個別の4連結経路とし、路盤、左右レールの順に合成して枕木を描かないことで、斜線路の点描化より構造線の連続性を優先する。

表示解像度内で全体が並走し両端も近い線路だけは鉄道表示代表へ間引くが、元の線路データは統合・削除しない。交差線と分岐線は残す。2026-08-29にstandalone testからWeb本番へ範囲を広げ、地下鉄、鉄道トンネル、索道は従来描画を維持する。
